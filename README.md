# 健身生活 RPG

一个面向个人使用的本地健身与饮食习惯记录工具。它把每日步数、散步、力量训练、热身拉伸和健康晚餐转化为 RPG 任务、经验值、等级、称号和每周挑战。

项目不需要账号、数据库或云同步。记录默认保存在浏览器 `localStorage` 中。

## 项目特点

- **健身记录**：记录体重、步数、散步时间、训练类型、训练时长、完成度、RPE、疲劳和酸痛情况。
- **饮食记录**：记录晚饭类型和晚饭质量。
- **每日任务**：根据当天记录自动结算任务和经验，不需要重复手动打卡。
- **动态训练目标**：根据最近训练在上半身、下半身、全身和轻恢复之间轮换。
- **RPG 成长**：包含等级、经验条、称号、连续打卡、升级反馈和打卡保护券。
- **每周挑战**：不同等级解锁不同挑战，每周完成后获得额外经验。
- **训练推荐**：提供热身、主训练、冷身拉伸、强度和恢复建议。
- **最近 7 天统计**：汇总任务、经验、运动次数、步数、训练和饮食情况。
- **本地优先**：核心功能离线可用，个人数据不会自动上传。
- **可安装 PWA**：可安装到桌面，以独立应用窗口运行。
- **可选 AI 建议**：通过本机 Node.js 代理调用 OpenAI API，API Key 不进入浏览器代码。

## 工作方式

每日记录是应用中的唯一事实来源：

```text
填写当天记录
    ↓
自动检查任务条件
    ↓
发放经验并更新等级
    ↓
更新连续打卡、周挑战和训练建议
```

当前每日任务：

| 任务 | 完成条件 | 奖励 |
| --- | --- | ---: |
| 达到 6000 步 | 当天步数不少于 6000 | 25 exp |
| 散步 20 分钟 | 当天散步不少于 20 分钟 | 30 exp |
| 今日动态训练 | 完整完成系统指定的训练类型 | 40 exp |
| 热身和拉伸 | 在记录中勾选已完成 | 20 exp |
| 健康晚餐 | 晚饭质量选择“健康” | 25 exp |

每项任务每天只能结算一次，重复编辑或保存不会重复获得经验。

## RPG 系统

初始等级为 `Lv.1`，每一级所需经验为：

```text
当前等级 × 100
```

等级会解锁称号与周挑战，但不会强制提高训练时长、组数或 RPE。

| 等级 | 称号 / 解锁内容 |
| --- | --- |
| Lv.1 | 起步者 |
| Lv.2 | 行动者；解锁“步行探索” |
| Lv.3 | 规律建立者；解锁“力量基础” |
| Lv.5 | 稳定训练者；解锁“均衡一周” |
| Lv.8 | 恢复管理者；解锁“恢复管理” |
| Lv.10 | 长期主义者 |

每达到 5 的倍数等级会获得一张连续打卡保护券。中断一天后重新打卡时，系统可以自动消耗保护券延续 streak。

## 快速开始

### 推荐方式

需要 Node.js 18 或更高版本。

```powershell
npm start
```

浏览器打开：

```text
http://127.0.0.1:4173
```

项目没有第三方 npm 依赖，因此不需要执行 `npm install`。

### 直接打开

也可以直接双击 `index.html`。本地记录和规则推荐可以使用，但以下功能要求通过本机服务访问：

- 安装为桌面 PWA
- Service Worker 离线缓存
- 可选 OpenAI 建议

## 安装到桌面

1. 运行 `npm start`。
2. 使用 Edge 或 Chrome 打开 `http://127.0.0.1:4173`。
3. 点击页面顶部的“安装到桌面”，或浏览器地址栏中的安装图标。

安装后可以从桌面或开始菜单打开“健身生活 RPG”，应用会使用专属 Logo 和独立窗口。

## 可选 AI 建议

AI 功能不是核心功能，也不会影响本地规则推荐。

不要把 API Key 写入前端文件。请在启动服务前将其设置为环境变量：

```powershell
$env:OPENAI_API_KEY="你的 API Key"
$env:OPENAI_MODEL="gpt-5.2"
npm start
```

浏览器只请求本机的 `server.js`，由本机代理调用 OpenAI API。

## 数据与隐私

应用使用两个 localStorage 键：

```text
localFitnessRecords
fitnessRpgState
```

- `localFitnessRecords`：健身、身体状态和晚饭记录。
- `fitnessRpgState`：经验、等级、任务历史、周挑战和保护券。

数据与具体浏览器和访问地址绑定。例如，直接打开 `index.html` 与访问 `http://127.0.0.1:4173` 可能拥有不同的 localStorage 数据。

页面中的“清空健身记录”只清空健身记录，不会删除 RPG 进度。

## 手动测试

1. 保存一条 `6500` 步的记录，确认步数任务自动完成。
2. 填写散步 `20` 分钟，确认散步任务完成。
3. 完整完成页面指定的今日训练，确认训练任务完成。
4. 勾选热身拉伸并选择健康晚餐，确认相应经验到账。
5. 再次保存同一天记录，确认经验不会重复增加。
6. 刷新页面，确认记录和 RPG 状态保留。
7. 升到 Lv.2，确认称号、升级弹窗和周挑战更新。
8. 完成周挑战后再次保存，确认挑战奖励只发放一次。

## 技术栈

- HTML
- CSS
- 原生 JavaScript

- localStorage
- PWA / Service Worker

没有使用 React、Vue、数据库或第三方运行时依赖。

## 当前定位

这是一个个人项目，重点是让健身和饮食记录更容易坚持。它不是医疗、康复或专业训练处方工具；如果出现明显疼痛、受伤或健康风险，应停止训练并寻求专业意见。
